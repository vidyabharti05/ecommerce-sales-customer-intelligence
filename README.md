# E-commerce-Sales-Customer-Intelligence System
## Project Overview
This project analyzes e-commerce sales, customer behavior, product performance, seller performance, and delivery patterns using Python and Machine Learning.
E-commerce sales, customer behavior, product and delivery analysis using Python and Machine Learning.
##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

##  Analysis Performed

- Sales Analysis
- Customer Analysis
- Product Analysis
- Seller Analysis
- Delivery Analysis
- Customer Segmentation
- Machine Learning Classification

##  Machine Learning

A Logistic Regression model was used for customer classification.

Model evaluation included:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

##  Key Business Insights

- Total Sales: ₹15.84 Million
- Repeat Customers: 2,997
- One-time Customers: 93,099
- Average Delivery Time: 12.1 days
- Late Orders: 6,535
- Top Sales Category: beleza_saude
- Category with Most Late Orders: cama_mesa_banho

##  Business Value

The analysis can help e-commerce businesses understand customer behavior, identify valuable customer groups, analyze product performance, and improve delivery operations.
